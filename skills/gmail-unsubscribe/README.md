# Gmail Unsubscribe

Review unwanted lists with account-specific protections and explicit consent.
Start with [SKILL.md](SKILL.md). Failed authentication means hold; unsubscribe
never implies permission to block or create a filter.

Copy this entire folder into your host's skill directory. The bundled references
carry the shared safety and personalization instructions. Start with “review my
unwanted email lists”; setup is read-only. Store actual preferences and history
outside the skill folder and repository, isolated by verified account ID.

The YAML file is a template with no active grants. Existing v1 preferences can
be reviewed and migrated; old cut rules must not become action permissions.
[Scheduled reviews](scheduled-task.md) propose changes without executing them.
